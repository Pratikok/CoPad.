# CoPad.

A shared writing room with a warm retro editor, light and dark themes, rich text formatting, custom text and highlight colors, live cursors, local room history, PDF export, and optional typewriter key sounds.

## How room sharing works

CoPad is a hosted web app. Anyone with a room link can join — no sign-up, no account, no install.

1. Open CoPad at its public web address.
2. Enter your display name when prompted.
3. Create a room (or open one from your room history).
4. Click **Share room** and copy the link.
5. Send the link to anyone. They open it, enter their name, and join the same shared document.

Edits, formatting, titles, and named cursors sync live between everyone in the room. Room content is stored durably in the cloud database, so rooms survive reloads and reconnects.

## UniCode houses

A UniCode house links your room history with friends. Share your six-digit UniCode or enter someone else's to join their house. House members see each other's rooms and who's currently in them.
